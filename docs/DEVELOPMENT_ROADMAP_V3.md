# Latticewake development roadmap v3

> Historical architecture sequence. The active productization and AUv3 plan is
> [Productization Roadmap v4](PRODUCTIZATION_ROADMAP_V4.md).

Latticewake's defining loop is: play the terrain, shape its traversal, grow it
into a scene, freeze trusted components, preview deterministic variations, and
capture or sequence the result. Terrain remains the defining instrument through
Cycle 040.

## Meta-cycle I — instrument truth

- Cycle 033: Scene v1, stable component identities, legacy migration, and one
  portable RenderPlanBuilder.
- Cycle 034: luminous Metal Terrain Stage with unambiguous selected, enabled,
  sounding, muted, modulation, frozen, preview, and saved states.
- Cycle 035: one input multiplexer and exact-route keyboard, pointer, MIDI, and
  MPE admission.

## Meta-cycle II — living terrain language

- Cycle 036: independent Surface, Traversal, and Articulation editing.
- Cycle 037: selected-parameter modulation with explicit scope and a 32-route
  overview matrix.
- Cycle 038: deterministic offline image- and audio-derived Surface assets.
- Cycle 039: Freeze and Grow previews with explicit Accept, Reject, and Undo.
- Cycle 040: distinct deterministic Drone, Pad, Motif A, and Motif B providers.

## Meta-cycle III — instrument ecosystem

- Cycle 041: ExpressiveEngine rack and terrain-excited modal resonator.
- Cycle 042: scene chains, semantic capture, stems, MIDI/MPE, and asset-bound
  export without a DAW timeline.
- Cycle 043: typed Hermes, Codex, local-agent, and optional on-device-first Apple
  Intelligence proposals through the same Grow boundary.
- Cycle 044: focused AUv3 companion using the admitted standalone contracts.

Every cycle closes only with relevant normal, sanitizer, Swift, callback,
signed-app, exact-SHA hosted, handoff, tag, and push evidence. Technical signal
or device evidence never substitutes for human listening or aesthetic review.
